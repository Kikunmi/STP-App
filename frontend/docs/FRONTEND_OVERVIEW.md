# Smart Travel Planner Frontend

## Goal

Build a modern responsive web application that connects to the Travel Planner API.

Users can:

- Register
- Login
- Create Trips
- Manage Trips
- Build Itineraries
- Track Expenses
- Save Favorites
- Share Trips
- View Recommendations

## Tech Stack

React
Vite
TailwindCSS
React Router
Axios
React Hook Form
Zod
React Query (TanStack Query)
Context API
