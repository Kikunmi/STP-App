# Smart Travel Planner & Itinerary Builder

## Goal

Build a travel planning platform where users can:

- Register and log in
- Create trips
- Build itineraries
- Track travel expenses
- Save destinations
- Share trips
- Receive smart recommendations

## Tech Stack

Backend:

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication

Testing:

- Mocha
- Chai

Future Integrations:

- Google Places API
- OpenWeather API
- OpenAI API
